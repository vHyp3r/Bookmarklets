# Bookmarklets

A small assortment of useful, practical, and just-for-fun bookmarklets.

To use a bookmarklet, open its source file for the current JavaScript, copy the
contents, and save it as the address of a new bookmark.

## Utility

- [Copy page title and URL](bookmarklets/copy-page.js) - Copies `Title: URL` to
  the clipboard.
- [Toggle dark mode](bookmarklets/dark-mode.js) - Applies a readable dark theme
  to the current page and toggles it off on the next click.
- [Reader view](bookmarklets/reader-view.js) - Hides page navigation and chrome
  to focus on the main content.

## Fun

- [Party mode](bookmarklets/party-mode.js) - Adds colorful animations to the
  page.
- [Rainbow cursor](bookmarklets/rainbow-cursor.js) - Leaves a rainbow trail
  behind the cursor.

## Development

Each file contains plain JavaScript starting with a bookmarklet-compatible
IIFE. Test a script by opening the browser console on a page and pasting its
contents.
